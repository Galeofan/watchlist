# watchlist
Сервис для учёта просмотренного медиа-контента (фильмы, сериалы), позволяющий пользователю фиксировать просмотры, просматривать историю, фильтровать данные и получать базовую аналитику. Проект служит учебной платформой для освоения полного цикла разработки: frontend (React + TypeScript), backend (Spring Boot 3.4), PostgreSQL, Docker.
